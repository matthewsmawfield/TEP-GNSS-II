# Superseded CMB visualization

These files are retained only as a reproducibility record of the earlier
antiparallel sign convention. They must not be used as current evidence for a
CMB-frame detection.

The corrected prograde convention gives a best-fit annual-phase direction of
RA = 6°, Dec = +4°, approximately 6° from Earth's aphelion velocity tangent.
The directed CMB-apex template is anti-phase (r ≈ −0.546), and the Solar Apex
is null. The live manuscript therefore uses the regenerated static figures and
does not embed this dashboard.
